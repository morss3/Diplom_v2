## Диплом версия 1
### Пару слов об устройстве на котором все выполнялось
- Процессор: Intel core i5-12500Н
- GPU: Nvidia Geforce rtx 3050 (как оказалось, не была задействована в работе, все считалось на процессоре, поэтому время в экспериментах может быть большим)
- Память: 16 ГБ
### Что было сделано?
Я сравнила несколько методов векторизации: "binary", "bag of word", "tfidf_std", "tfidf_bigrams", "word2vec","doc2vec","bert" в задаче классификации (использовала модель логистической регрессии) и в задаче кластеризации (K-means).
---
Добавила визуализацию в streamlit

### Что есть в этом репозитории?
1. Файл ```notebooks/01_classification_comparison```: сравнение нескольких методов векторизации в задаче классификации. Результат в ```results/tables/classification_compare.csv```. Также вектора, которые сделаны файлом **prepare_vectors.py** я сохранила ```data/processed/{name_dataset}test_bert_vectors.npy```. Для оптимизации сразу в ноутбуке рисую графики и таблицы (рса, матрицу ошибок, отчет) для топ 2 методов. Сохраняю результаты в соответствующей папке.
---
2. Файл ```notebooks/02_clasterization_comparison```: здесь эксперимент с кластеризацией. Также взяла все те же методы, какие использовала в работе с классификацией. Результаты в ```results/tables/{name_dataset}/clusterization_compare.csv```. Так как я заранее сохранила вектора, то здесь я просто их загружала и не делала повторно процесс векторизации. Для оптимизации сразу в ноутбуке рисую графики и таблицы (рса для исходных данных, для тех, что предсказала модель, и аналогичнно рса tsne) для топ 2 методов. Сохраняю результаты в соответствующей папке.
---
3. ```app.py```: само приложение стримлит, запускается после того как выполнен код в ноутбуках. ВЫбираем датасет (всего их 3), задачу (классификация, кластеризация). Смотрим результаты: итоговая сравнительная таблица, график точность vs время, визуализация (для одного выбранного метода, для сравнения двух методов). По умолчанию в выпадающих списках стоят значения топ двух методов. Если сохранились векторы, то есть возможность визуализировать и други методы, не только из топ 2
---
4. ```visualizer.py```: функции для отрисовки графиков
---
5. ```ui_helpers.py```: функции для стримлит страницы
---
6. ```config.py```: словари, пути к папкам и тд

---
6. Файл ```prepare_vectors.py```: для каждого метода сохраняю полученные векторы в папку ```data/processed/{name_dataset}```. У кажого метода считаю время, затраченное на векторизацию, и сохраняю в ```data/processed/{dataset_name}/vectorization_time.json```.
